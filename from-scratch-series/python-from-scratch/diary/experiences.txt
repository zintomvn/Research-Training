# Steps by step solution to problem solving
Step 1: Read and Restate the Problem

Step 2: Think of the simple solution

Step 3: Find the repeat work

Step 4: Trace the code manually

Step 5: Test edge cases

Step 6: Look at the solution after 25-35 minutes

Step 7: Close the Solution and Reimplement It
- Understand the main idea.
- Close the solution page.
- Write the code again from scratch.
- Explain the purpose of each variable.
- State the time and space complexity.
- Solve the problem again several days later.
